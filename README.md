# iOS 27 Launcher for Android

Full visual iOS-style launcher with Dynamic Island and smooth animations.

## Features
- Liquid Glass design system (frosted panels, specular borders, soft reflections)
- Dynamic Island with multiple states (Notification, Media, Timer) + spring physics
- App folders with glass overlay
- Icons with glass edge highlights + press animation
- Liquid Glass dock
- Loads all installed apps
- Can be set as default home screen

## How to Build the APK

1. Install **Android Studio** (latest stable)
2. Open this folder as a project in Android Studio
3. Let Gradle sync (first time may download dependencies)
4. Connect your phone or use emulator
5. Click **Build > Build Bundle(s) / APK(s) > Build APK(s)**
6. Or run directly on device

### Set as Default Launcher
After installing:
- Press Home button
- Select "iOS 27" and choose "Always"

## Notes
- Min Android 8.0 (API 26)
- QUERY_ALL_PACKAGES is used so all apps appear (required for launchers)
- Dynamic Island is a visual recreation with spring physics
- Icons are pulled live from your device
